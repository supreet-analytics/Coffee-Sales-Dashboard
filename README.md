# ☕ Coffee Sales Dashboard (Excel)

This project is an interactive Excel dashboard created to analyze coffee sales data across different countries, customers, and product categories. It provides actionable insights for business stakeholders using a clean and dynamic visual format.

---

## 🎯 Objective

To design a business-friendly dashboard that enables:
- Quick overview of total sales
- Identification of top customers
- Country-wise performance tracking
- Product demand visualization

---

## 📁 Dataset Structure

The dashboard was built using multiple structured sheets:
- **orders** – Contains transaction-level data
- **customers** – Customer information including country
- **products** – Product details
- **TotalSales** – Aggregated monthly sales
- **Top5Customers** – Pre-calculated top customer data
- **CountryBarChart** – Country-level sales distribution

---

## 🛠 Tools & Techniques

- **Microsoft Excel**
  - Pivot Tables
  - Slicers (for product and country filtering)
  - Bar and Line Charts
  - Dynamic KPIs and Conditional Formatting

---

## 📊 Dashboard Features

- 📈 **Monthly Sales Trend Analysis**
- 🏆 **Top 5 Customers by Sales**
- 🌍 **Country-wise Sales Comparison**
- ☕ **Category/Item-level Filtering**
- ⚡ **Real-time KPI updates with slicers**

---

## 💡 Business Insights

- The dashboard helps identify high-value customers and sales hotspots by region.
- Monthly analysis reveals peak periods and seasonal patterns.
- Easy filtering makes it intuitive for non-technical users.
